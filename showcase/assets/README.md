# Showcase media provenance

- demo-atlas.png and demo.json: deterministic, unshaded renderings of PixelDoll app/public/fixtures/s2, using its MIT compositor. Exported on 2026-10-23 from PixelDoll commit 003bef2; only stored Walk frames, heads and outfits, with no new generations. The atlas is 64 px per cell; metadata records layout and original IDs.
- obsidian-stage.png and porcelain-stage.png: AI-generated environment plates created during the user-authorized PixelDoll round-five design work; reused unchanged with the owner’s authorization to publish this MIT showcase. No third-party game screenshot or copied Asemulator visual is included. These images are offered under the repository MIT terms to the extent rights apply, without claiming copyright status beyond the underlying rights.
- Lucide icons are optional peer artwork bundled into the showcase under their original ISC/Feather MIT terms; see ../../NOTICE.md.

All media is demo-only, committed for a self-contained build, and excluded from the npm-compatible package archive. No environment imagery or character effects alter the original sprite pixels.
